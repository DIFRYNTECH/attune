# Attune - Roadmap

This roadmap prioritises emotional safety, speed, and clarity.
Each phase should leave the app usable, even if we stop there.

---

## Phase 0 - Foundations (DONE / IN PROGRESS)

Goal: A working skeleton that proves the concept.

✔ Web app first (React + Vite)  
✔ Mobile-first mindset  
✔ Four core screens defined  
✔ Heart & soul articulated  
✔ Local-only persistence (no backend)  

Outcome:
- Attune runs in the browser
- State persists across refreshes
- Architecture is clean enough to extend

---

## Phase 1 - Mobile Calm Pass (NEXT)

Goal: Make Attune feel **calm and usable on a phone**.

### Visual & Layout
- Switch to **mobile-first layout**
- Reduce vertical density
- One primary card per screen
- Collapse or hide “Quick status” on mobile
- Move navigation to **bottom nav**
- Increase breathing room (padding, spacing)

### Navigation
- Bottom navigation: Check-in / Wheel / My Day / Weekly
- Remove top pill navigation on mobile
- Keep current screen visually obvious

### Outcome
- App no longer feels overwhelming
- Screens feel intentional, not crowded
- Looks like a real mobile app (not a shrunk website)

---

## Phase 2 - Check-in Screen (Core Loop Start)

Goal: Make the first interaction emotionally safe and simple.

### Check-in
- Mood / energy / body inputs
- Optional (skip-friendly)
- Clear pace selection (Rest → Brave)
- Gentle level suggestion
- No forced flows

### Outcome
- User can check in without pressure
- Pace feels like permission, not obligation

---

## Phase 3 - Wheel Experience (Playful, Not Addictive)

Goal: Reduce decision fatigue through gentle play.

### Wheel
- Calm spin animation (no casino vibes)
- Tasks aligned to selected pace
- “Spin again” always allowed
- “Add to My Day” is optional

### Outcome
- Choosing a task feels light
- No guilt for rejecting spins

---

## Phase 4 - My Day (Gentle Follow-through)

Goal: Make action feel achievable.

### My Day
- 2–5 tasks max (soft limit)
- Clear “done” interaction
- Gentle encouragement on completion
- Removing a task feels neutral, not bad

### End Day
- “End day gently” flow
- Praise presence, not output
- Reset without punishment

### Outcome
- Doing something feels good
- Doing nothing doesn’t feel bad

---

## Phase 5 - Weekly Reflection (Meaning Without Metrics)

Goal: Reflection without judgment.

### Weekly
- Archetype-based reflection
- Language focused on care + presence
- Returning after gaps strongly valued
- No charts, no streaks, no rankings

### Outcome
- User feels seen, not measured
- Week feels like a story, not a report

---

## Phase 6 - Polish & Trust

Goal: Make Attune feel safe enough to keep.

### UX Polish
- Microcopy pass
- Animation smoothing
- Remove any sharp edges

### Trust
- Clear “local only” messaging
- Gentle explanation of data storage
- No dark patterns

### Outcome
- User trusts Attune
- App feels calm, consistent, and intentional

---

## Phase 7 - Deployment & Sharing

Goal: Put Attune in someone’s hands.

### Deploy
- Vercel or Netlify
- Enable PWA “Add to Home Screen”
- Test on real phones

### Share
- Private link
- Observe real usage
- Collect feelings, not metrics

### Outcome
- Real humans use Attune
- We learn what actually matters

---

## Phase 8 - Decide the Future

Only after real use.

Possible paths:
- Keep as a free companion
- Add optional paid features
- Wrap into native app
- Introduce accounts/backend

Decision driver:
**Does Attune genuinely help people come back to themselves?**

If yes - we continue.
If no - we adjust gently.
