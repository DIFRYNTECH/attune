# Attune Brand Video

This Remotion composition builds a calm vertical brand film for Attune.

## Preview

```powershell
npm run video:studio
```

Open the local Remotion Studio URL it prints, usually `http://localhost:3002`, then select `AttuneBrandVertical`.

## Render Verification Stills

```powershell
npm run video:still:opening
npm run video:still:middle
npm run video:still:closing
```

The stills render into `remotion/renders/`.

## Render MP4

```powershell
npm run video:render
```

The video renders to `remotion/renders/attune-brand-vertical.mp4`.
